# Agent catalog

**Planning crew (always used, not part of the team pick):** planner, researcher, architect,
env-setup. They run the spec, HLD, LLD and environment stages. The Orchestrator runs
`taskgit.sh approve/reject/record` itself; git-pr is optional (only for a commit message that
needs real summarising).

**Team pick (after the HLD is approved):** map each HLD module to the agents that build it,
using "Pick when" below. Recommend tester, reviewer, debugger and docs for any project with
code. Show the module → agent mapping on the team card so the owner sees why each one is there.

## Typical teams

The build team only: the planning crew (planner, researcher, architect, env-setup) runs every
project anyway.

- **Full-stack web app**: backend-coder, frontend-coder, tester, reviewer, debugger, docs, devops
- **RAG / LLM app**: the full-stack team minus frontend-coder (keep it if there's a UI) + rag-engineer, prompt-engineer, evaluator; + agent-engineer if it uses tools/agents
- **ML model project**: data-acquisition, data-cleaner, eda, modeler, evaluator, explainer, tester, reviewer, debugger, docs; + mlops if served
- **Analysis / A-B test**: data-acquisition, data-cleaner, eda, statistician, visualizer, insights-reporter, reviewer
