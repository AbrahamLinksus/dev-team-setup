# Answer sheet · production benchmark (plugin run)

Answer the same way every time so runs are comparable. Count every tap or message you send.

| When the plugin asks… | Answer |
|---|---|
| Repo name / visibility | `bench-issue-tracker` · Private |
| Spec questions | Answer from `spec.md`. If it doesn't say, pick the **(Recommended)** option |
| "Decide for me" offered and the spec is silent | Decide for me |
| Spec, HLD, LLD, install, task-list cards | Approve |
| Team | Approve the proposed team, add no optional agents |
| Stack / package cards | Whatever matches the spec's stack (`spec.md` → Stack); otherwise **(Recommended)** |
| Task result cards | Approve if every goal is ✅. If a goal is ❌, "Request changes" once with *fix the ❌ goal* |
| Milestone card | **Approve + continue in a fresh session** |
| Change requests | Don't start any. If the plugin asks whether something is a change request, answer "fix to this task" |
| Handover card | Approve |

If the same task fails 3 times in a row, note it in `results.md` (Notes) and answer the
plugin's decision card with its **(Recommended)** option.
