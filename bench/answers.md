# Answer sheet for the plugin run

Answer the same way every time so runs are comparable.

| When the plugin asks… | Answer |
|---|---|
| Repo name / visibility | `bench-link-shortener` · Private |
| Spec questions | Answer from `bench/spec.md`. If the spec doesn't cover it, pick the **(Recommended)** option. |
| "Decide for me" offered and spec is silent | Decide for me |
| HLD / LLD / install / plan cards | Approve |
| Team | Approve the proposed team; add no optional agents |
| Stack / package decision cards | Pick whatever matches the spec's fixed stack; otherwise **(Recommended)** |
| Task result cards | Approve if every goal is ✅. If any goal is ❌, choose "Request changes" once with "fix the ❌ goal" |
| Milestone card | **Approve + continue in a fresh session** (that's the token-saving path being tested) |
| Handover card | Approve |

Settings for the run: `approval_mode=every-task`, `cost_mode=quality` (the defaults).

Keep a tally of every time you had to type or tap something: that's "Your interventions"
in the results table.
